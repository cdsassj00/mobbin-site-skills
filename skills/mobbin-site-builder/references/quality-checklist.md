# 완료 검증

- [ ] 레퍼런스 이미지와 URL의 확인 여부를 기록했다.
- [ ] 섹션 순서, 전체 폭, 영역 비율, 콘텐츠 밀도를 비교했다.
- [ ] 타이포그래피, 간격, 이미지 비율, 강조 색을 비교했다.
- [ ] 핵심 사용자 흐름을 처음부터 완료 화면까지 조작했다.
- [ ] 입력 오류, 빈 결과, 선택 상태, 되돌아가기를 확인했다.
- [ ] 데스크톱과 모바일에서 가로 넘침과 겹침을 확인했다.
- [ ] 키보드 이동, 포커스, 입력 레이블, 모달 닫기를 확인했다.
- [ ] 프로젝트 빌드와 필요한 타입·린트 검사가 통과했다.
- [ ] 콘솔 오류와 실패한 이미지 요청을 확인했다.
- [ ] 데모 동작, 미확보 에셋, 추정한 반응형 규칙을 알렸다.

수행할 수 없었던 항목은 체크하지 않고 이유를 결과에 기록한다.
