# 사이트 유형별 구현 시작점

아래는 일반적인 구성이다. 실제 Mobbin 사이트를 수집·분석한 목록이 아니다. 선택한 레퍼런스의 구성이 항상 우선한다.

| 유형 | 주요 화면 | 핵심 흐름 | 집중할 요소 |
| --- | --- | --- | --- |
| SaaS 랜딩 | 홈, 기능, 요금제 | 가치 확인 → 요금 비교 → 가입 진입 | 제목 위계, 제품 이미지, 요금표 |
| SaaS 대시보드 | 개요, 목록, 상세, 설정 | 탐색 → 필터 → 상세 → 편집 | 사이드바, 데이터 밀도, 상태 표시 |
| 커머스 | 상품 목록, 상세, 장바구니 | 검색 → 옵션 선택 → 담기 → 주문 데모 | 이미지 비율, 가격, 옵션, 모바일 CTA |
| 콘텐츠·미디어 | 피드, 검색, 글 상세 | 발견 → 읽기 → 저장 | 읽기 폭, 카드 계층, 메타정보 |
| 여행·예약 | 검색, 결과, 숙소 상세 | 날짜·인원 → 필터 → 상세 → 예약 데모 | 날짜 선택, 결과 카드, 가격 요약 |
| 금융 | 자산 개요, 거래 내역, 거래 상세 | 개요 → 조회 → 거래 데모 확인 | 수치 정렬, 단위, 상태, 확인 단계 |
| 생산성 | 보드, 목록, 작업 상세 | 추가 → 수정 → 상태 이동 | 밀도, 편집, 선택 상태, 빈 화면 |
| 커뮤니티 | 피드, 게시물, 프로필 | 탐색 → 작성 → 댓글 | 작성 도구, 상호작용, 프로필 계층 |
| 교육 | 과정 목록, 과정 상세, 학습 화면 | 선택 → 수강 데모 → 진도 확인 | 과정 구조, 진도, 학습 내비게이션 |
| 포트폴리오 | 프로젝트 목록, 상세, 소개 | 작품 탐색 → 상세 → 연락 진입 | 이미지 배치, 타이포그래피, 전환 |

## 조합 예시

주 레퍼런스 A의 대시보드 레이아웃을 따르고 B의 검색·필터 상호작용을 적용한다. 둘의 토큰을 무작정 섞지 않고 A의 글자·간격·색상 체계로 B의 컴포넌트를 조정한다.
