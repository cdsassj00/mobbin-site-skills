# Mobbin MCP 사용 규칙

사용자가 Mobbin 레퍼런스로 만들기를 요청하면 캡처를 요구하기 전에 연결된 MCP 도구를 확인하고 사용한다.

## 도구 선택

- `mobbin_search_screens`: 대시보드, 상품 상세 등 개별 화면. `platform: web`.
- `mobbin_search_sections`: 히어로, 요금제, 푸터 등 사이트 섹션.
- `mobbin_search_flows`: 가입, 팀 초대, 체크아웃 등 여러 단계의 사용자 여정. `platform: web`.

실제 제공되는 도구의 스키마를 확인한다. 도구 이름의 서버 접두사는 환경에 따라 다를 수 있다.

## 검색

- 검색 한 번에는 하나의 화면·섹션·여정만 구체적인 영어 문장으로 설명한다.
- 특정 서비스가 필요하면 query에 서비스 이름을 포함한다.
- 처음에는 적은 결과 수로 검색하고 확인한 뒤 필요할 때 확장한다.
- `output_destination`은 현재 작업의 결과물로 선택한다. 구현은 `code`, 자료 보관은 `reference_library`, 명세 작성은 `doc`. 같은 작업의 호출에서는 같은 값을 유지한다.
- `task_intent`는 전체 작업을 요약한 영어 한 문장으로 유지한다.

## 결과 확인 및 저장

- 반환 이미지를 직접 보고 분석한다. 서비스 이름과 메타데이터만 보고 화면을 설명하지 않는다.
- 흐름 검색은 일부 단계의 프리뷰만 반환할 수 있다. 전체 순서가 필요하면 모든 단계의 고해상도 파일을 받아 확인한다.
- 저장할 때는 `image_url`에서 고해상도 파일을 다운로드한다. 프리뷰를 원본으로 저장하지 않는다.
- 이미지 URL은 30일 뒤 만료되므로 장기 출처는 `mobbin_url`을 사용한다.
- 공개 저장소에는 기본적으로 출처·관찰·구현 규칙을 넣고, 원본 파일은 Git에서 제외된 `assets/`에 보관한다.
- 화면을 사용자에게 소개할 때 해당 `mobbin_url` 링크를 함께 제공한다.
- `ai_usage_notice`가 있으면 text를 서식과 줄바꿈까지 그대로 별도 블록으로 사용자에게 전달한다.
