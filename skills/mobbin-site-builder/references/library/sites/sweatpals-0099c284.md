# Sweatpals

이 문서는 수집한 화면·섹션·흐름의 구현 참고 명세다. 전체 사이트 분석을 뜻하지 않는다.

## 수동 결제 상품 선택

- 자료 유형: screen
- 출처: [Sweatpals — Mobbin](https://mobbin.com/screens/0099c284-2e58-43ca-9eb5-2ea41538ece6)
- 확인 날짜: 2026-10-11
- 패턴: checkout, quantity-selector

### 직접 관찰

- 검정 결제 사이드 패널. 상단 Add Items→Checkout→Confirmed 단계, 고객 요약·검색·유형 칩, 품목별 수량 +/-와 하단 총액·Next 버튼.

원본 파일: `assets/library/0099c284-2e58-43ca-9eb5-2ea41538ece6.jpg` (Git 제외).

### 구현에 적용

- 위 관찰의 열 구성, 이미지 비중, 제목 위계, 색 대비를 먼저 구현한다.
- 화면에 보이는 입력·선택·필터·이동 요소를 실제 동작으로 연결한다. 정적 이미지로 확인되지 않는 동작은 구현 제안으로 기록한다.
- 해당 패턴의 [구현 플레이북](../../playbooks.md)을 읽고 완료 조건을 적용한다.
- 모바일 구성과 정확한 토큰은 이 자료만으로 확정하지 않는다. 모바일 자료를 추가 검색하고 고해상도 원본에서 측정한다.
