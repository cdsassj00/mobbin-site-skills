# Base

이 문서는 수집한 화면·섹션·흐름의 구현 참고 명세다. 전체 사이트 분석을 뜻하지 않는다.

## 금융·거래 관리

- 자료 유형: screen
- 출처: [Base — Mobbin](https://mobbin.com/screens/90bfce7d-2fe7-4e0d-8603-c2c57651a7ef)
- 확인 날짜: 2026-10-11
- 패턴: finance, dashboard

### 직접 관찰

- 지갑 활동 목록. 왼쪽 간단한 네 메뉴, 중앙 좁은 거래 표에 자산 아이콘·거래 설명·금액·날짜. 위 자산·네트워크 필터와 녹색 양수.

### 구현에 적용

- 위 관찰의 열 구성, 이미지 비중, 제목 위계, 색 대비를 먼저 구현한다.
- 화면에 보이는 입력·선택·필터·이동 요소를 실제 동작으로 연결한다. 정적 이미지로 확인되지 않는 동작은 구현 제안으로 기록한다.
- 해당 패턴의 [구현 플레이북](../../playbooks.md)을 읽고 완료 조건을 적용한다.
- 모바일 구성과 정확한 토큰은 이 자료만으로 확정하지 않는다. 모바일 자료를 추가 검색하고 고해상도 원본에서 측정한다.
