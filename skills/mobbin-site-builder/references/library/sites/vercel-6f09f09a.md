# Vercel

이 문서는 수집한 화면·섹션·흐름의 구현 참고 명세다. 전체 사이트 분석을 뜻하지 않는다.

## 연동 디렉터리

- 자료 유형: section
- 출처: [Vercel — Mobbin](https://mobbin.com/sites/sections/6f09f09a-ddb8-4581-ba7c-603a1d7920c7)
- 확인 날짜: 2026-10-11
- 패턴: integrations

### 직접 관찰

- 왼쪽 검색·연동 카테고리 목록, 오른쪽 Analytics·CMS별 세 열 흰 카드. 로고·이름·Template/Beta 상태·짧은 설명.

원본 파일: `assets/library/6f09f09a-ddb8-4581-ba7c-603a1d7920c7.jpg` (Git 제외).

### 구현에 적용

- 위 관찰의 열 구성, 이미지 비중, 제목 위계, 색 대비를 먼저 구현한다.
- 화면에 보이는 입력·선택·필터·이동 요소를 실제 동작으로 연결한다. 정적 이미지로 확인되지 않는 동작은 구현 제안으로 기록한다.
- 해당 패턴의 [구현 플레이북](../../playbooks.md)을 읽고 완료 조건을 적용한다.
- 모바일 구성과 정확한 토큰은 이 자료만으로 확정하지 않는다. 모바일 자료를 추가 검색하고 고해상도 원본에서 측정한다.
