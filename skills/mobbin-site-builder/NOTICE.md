# 자료 출처와 범위

- `assets/references/`에 포함된 웹 UI 스크린샷은 Mobbin MCP 결과의 고해상도 이미지이며 워터마크를 유지한다. 각 이미지 ID와 원 출처는 스킬의 `references/library.json`에 기록돼 있다.
- 원본 사이트의 브랜드·사진·문구·UI 이미지에 관한 권리는 각 권리자에게 있다. 이 저장소의 독자적인 스크립트·CSS·HTML 예제에 대한 라이선스와 구분한다.
- 관찰 메모는 직접 본 캡처 범위를 설명한다. 사이트 전체의 디자인 시스템을 역설계한 결과나 원본 사이트의 소스코드가 아니다.
- `styles.json`의 색상·간격·반경과 생성기 예제는 오프라인 구현을 위한 독자적인 프리셋이다. 원본에서 측정한 값으로 표시하지 않는다.
- 이미지 판독이 어려운 자료는 `needs-review`와 `usable: false`로 구분하며 기본 추천에서 제외한다.
