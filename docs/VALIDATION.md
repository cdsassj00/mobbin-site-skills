# 검증 기록

확인 날짜: 2026-10-18. 이 기록은 로컬 코드·파일·Chromium 실행 검증이며 Claude/Grok/OpenCode 계정별 모델 세션 실행 인증을 뜻하지 않는다.

## 통과한 검사

- 6개 Python 회귀 검사: 오프라인 이미지 경로 완결성, 목적·스타일 추천, 제외 스타일 적용, 18개 프리셋의 글자·버튼 대비, 4개 에이전트 설치·백업·외부 설치 덮어쓰기 거부, 생성기의 덮어쓰기 거부와 브랜드 입력 이스케이프.
- Chromium에서 8개 예제의 핵심 흐름: 요금 주기·플랜 선택, 작업 검색·상태 변경, 상품 수량·장바구니 합계·삭제·빈 결과, 기사 필터·저장, 문의 검증·데모 완료, 예약 날짜 오류·인원별 합계, 강의 완료·진도, 디렉터리 빈 검색.
- 8개 구조를 375px·1440px에서 확인했고 가로 넘침이 없었다.
- 18개 테마를 375px에서 열어 가로 넘침과 스크립트 오류를 확인했다.
- 브라우저 테스트는 외부 요청을 차단한 상태에서 통과했다. 외부 서비스 요청 0개.
- 모바일 대시보드에서 발견한 grid min-width 문제를 수정한 뒤 전체 관련 검사를 다시 통과했다.

## 재실행

Python 검사는 README 명령을 따른다. 브라우저 검사는 생성된 예제들을 localhost로 서빙하고 Playwright와 Chromium이 있는 환경에서 `node tests/browser.cjs`를 실행한다. 테스트용 생성 자료는 `tests/prepare_examples.py`로 만든다. Playwright는 검증 도구이며 배포되는 추천기·예제의 의존성이 아니다.

## 제품에 적용한 뒤 필요한 확인

원본 이미지와의 동일 뷰포트 시각 비교, 실제 콘텐츠 길이, 사용자 브랜드·API·데이터, 보조 기술과 목표 브라우저, 성능은 구현하는 프로젝트에 맞게 추가 확인한다. 일반적인 시작점 검증을 모든 결과 사이트의 검증으로 확대해서 설명하지 않는다.
