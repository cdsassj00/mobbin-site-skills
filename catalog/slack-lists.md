# Slack: 테이블 기반 생산성 사이트

## 출처와 확인 범위

- 확인 날짜: 2026-10-11
- 수집: Mobbin MCP, web
- 직접 관찰: MCP 인라인 프리뷰. 고해상도 원본 파일은 별도 저장.
- https://mobbin.com/screens/5db112b1-f04e-42ea-8d79-a15e961c4c82

## 관찰

자주색 상단 검색 바, 가장 왼쪽 아이콘 레일, 그 옆 Lists 사이드바, 오른쪽 흰색 테이블. 제목 아래 검색·필터·정렬·뷰 저장 도구가 있다. 행에는 작업, 상태 칩, 별 우선순위, 설명, 담당자가 보인다.

## 구현 명세

- 구성 요소: AppRail / ListSidebar / ListToolbar / TaskTable / StatusChip
- 동작 제안: 행 추가, 상태 변경, 검색·필터·정렬을 구현한다. 뷰 저장은 로컬 상태로 연결한다.
- 시각 규칙: 범용 통계 카드 대신 표와 도구막대 중심의 밀도를 유지한다.
- 반응형 제안 (모바일 원본 미확인): 작은 화면의 테이블은 열 우선순위를 정하고 필요한 경우 표 영역 안에서만 가로 스크롤한다.

## 완료 조건

핵심 행동을 조작할 수 있고, 선택 상태와 빈 결과를 처리하며, 데스크톱 레이아웃을 출처와 비교한다. 정확한 색상·폰트·치수는 고해상도 원본에서 측정 후 확정한다.
