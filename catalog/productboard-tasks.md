# Productboard: 작업 관리 대시보드

## 출처와 확인 범위

- 확인 날짜: 2026-10-11
- 수집: Mobbin MCP, web
- 직접 관찰: MCP 인라인 프리뷰. 고해상도 원본 파일은 별도 저장.
- https://mobbin.com/screens/6ca218fe-d545-49fd-abff-a0032ab03d2a

## 관찰

좁은 왼쪽 사이드바, 상단 Tasks 헤더와 검색·Create 버튼, 가운데 작업 목록, 오른쪽 상세 패널. 목록 배경은 연한 회색이고 상세 패널은 흰색이다. 상태는 회색·파랑·빨강·노랑·초록 점으로 구분된다.

## 구현 명세

- 구성 요소: 사이드바 / TaskList / TaskDetailPanel / StatusPicker / CommentInput
- 동작 제안: 작업 선택 시 오른쪽 상세를 갱신하고, 검색으로 목록을 좁힌다. 생성·상태 변경·댓글 추가는 로컬 데모로 구현한다.
- 시각 규칙: 목록과 상세의 높이를 맞추고 선택 강조는 옅은 파랑으로 유지한다.
- 반응형 제안 (모바일 원본 미확인): 모바일은 목록을 기본 화면으로 두고 상세를 별도 화면으로 전환한다.

## 완료 조건

핵심 행동을 조작할 수 있고, 선택 상태와 빈 결과를 처리하며, 데스크톱 레이아웃을 출처와 비교한다. 정확한 색상·폰트·치수는 고해상도 원본에서 측정 후 확정한다.
