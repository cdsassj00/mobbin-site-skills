- 수집: Mobbin MCP, web

## 관찰

왼쪽 아이콘 레일, 큰 상품 이미지와 세로 썸네일, 오른쪽 판매자·제목·별점·가격·배송 정보. 원두 옵션과 수량 아래 일회성 구매 / 구독 선택 카드가 있다. 검정 Buy now와 보라색 Add to cart가 나란히 배치된다.

## 구현 명세

- 구성 요소: ProductGallery / SellerSummary / VariantSelector / QuantityStepper / PurchaseMode / CartButton
- 동작 제안: 썸네일 변경, 옵션 선택, 수량 변경, 일회성·구독 선택, 장바구니 추가를 연결한다.
- 시각 규칙: 상품 이미지를 넓게 유지하고 구매 옵션과 CTA를 하나의 시각적 묶음으로 만든다.
- 반응형 제안 (모바일 원본 미확인): 모바일은 이미지 다음 구매 정보를 배치한다. 하단 고정 CTA는 구현 선택이며 캡처에서 확인한 사실이 아니다.

## 완료 조건

핵심 행동을 조작할 수 있고, 선택 상태와 빈 결과를 처리하며, 데스크톱 레이아웃을 출처와 비교한다. 정확한 색상·폰트·치수는 고해상도 원본에서 측정 후 확정한다.
